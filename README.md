# Árboles de Derivación Sintáctica

## Descripción

Este trabajo consiste en el análisis sintáctico de distintas oraciones mediante la construcción de árboles de derivación. El objetivo es representar gráficamente la estructura gramatical de cada oración, identificando sus componentes principales y las relaciones que existen entre ellos.

## Objetivos

* Comprender la estructura interna de las oraciones.
* Identificar sintagmas nominales y verbales.
* Reconocer determinantes, sustantivos, adjetivos, verbos, preposiciones y complementos.
* Representar visualmente el proceso de derivación mediante árboles sintácticos.

## Contenido del trabajo

Se realizaron árboles de derivación para diversas oraciones relacionadas con temas históricos y lingüísticos, entre ellas:

* Los aztecas hablan náhuatl.
* La dominación islámica disminuyó progresivamente.
* Los reyes católicos conquistaron Granada.
* El catalán es una lengua romance.
* Los mayas resistieron la colonización española.
* Los sacerdotes evangelizaban a los indígenas.
* Las lenguas minoritarias de España han entrado en una nueva etapa.
* El español es lengua oficial en diecinueve países de Latinoamérica.
* El terreno de Paraguay representaba desafíos de envergadura para los españoles.
* Los niños monolingües de desarrollo normal pasan por varias etapas.

## Metodología

Para cada oración se identificaron sus constituyentes sintácticos principales:

* O: Oración
* SN: Sintagma Nominal
* SV: Sintagma Verbal
* Det: Determinante
* N: Sustantivo
* Adj: Adjetivo
* V: Verbo
* P: Preposición
* CN: Complemento del Nombre
* SP: Sintagma Preposicional

A partir de estos elementos se construyeron árboles jerárquicos que muestran cómo se organiza cada oración desde la estructura general hasta las palabras individuales.

## Conclusión

La elaboración de árboles de derivación permite comprender de manera visual y ordenada la organización sintáctica de las oraciones. Esta herramienta resulta fundamental para el estudio de la gramática, ya que facilita el análisis de las funciones que cumple cada palabra dentro de una estructura lingüística determinada.
